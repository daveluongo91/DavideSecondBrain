# Raw sources

Questa cartella contiene materiale originale. Le fonti sono immutabili: l'agente può leggerle e spostarle da `inbox/` a `sources/`, ma non deve riscriverle.

- `inbox/`: materiale appena aggiunto e non ancora processato.
- `sources/`: fonti già ingerite.
- `assets/`: immagini e allegati locali delle fonti.
