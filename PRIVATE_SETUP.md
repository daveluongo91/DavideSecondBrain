# Impostazione delle note private

Non inserire informazioni sensibili nel repository pubblico.

## Opzione consigliata

Crea accanto a questo repository una cartella separata:

```text
second-brain-private/
├── health/
├── finance/
├── work-confidential/
└── personal/
```

Mantienila in un repository Git privato oppure soltanto in locale.

## Collegamento in Obsidian

Puoi aprire entrambe le cartelle come vault separati. Evita symlink verso materiale privato dentro il repository pubblico: possono essere facili da committare per errore.

## Informazioni da non pubblicare

- credenziali e token;
- indirizzi, numeri di telefono e documenti;
- dati sanitari;
- conti, debiti, redditi e contratti;
- informazioni interne aziendali;
